Gates CAI — a host codon table only means something for an organism that translates on host ribosomes.

Sets the ceiling μ is normalised against. A DNA rate judged on the RNA scale contributes almost nothing however fast it is for a DNA genome.

Columns: sequence_id, collection_date, location, host. Without dates μ cannot be estimated at all.

CDS features. Without it both coding indices are skipped.

CAI measures adaptation to the host's translational machinery, so pick the host this pathogen infects.

The birth–death process is scaled by 365.25 / generation time, so a value wrong by a factor of k moves Re by roughly the same factor — and Re carries the largest weight in the scheme. Left empty, the run uses 5 days, which suits a fast respiratory virus and little else.

Columns: date, new_cases. With real case counts Re is estimated by the Cori renewal equation, which recovers a known Re to within 0.02. Without them Re is inferred from tree shape alone, which is far weaker.
